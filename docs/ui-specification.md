# 界面与产品行为

保持共享游戏浏览、管理、私人存档/收藏/最近、账号及独立沉浸模式。手机首页/资料库/我的入口及桌面管理、4K和Player状态以统一docs/design评审源为准。列表采用有界服务端筛选/真实总数；不可恢复存档置灰并展示准确原因；未同步草稿提供重试/丢弃，不假成功。

游戏库、我的收藏、我的存档与最近游玩采用向下滚动自动追加加载，每次最多24条，服务端筛选、排序及真实总数不变。接近列表底部时读取下一页，同一列表不并发拉取下一页；底部显示已加载/总数、加载中、重试或已加载全部，并保留可键盘操作的“加载更多”入口。筛选变更从首批重置，取消旧请求，旧响应不能混入新结果；追加失败保留已加载内容并等待用户重试，空结果或已到总数后停止。删除、改名、收藏整理后按24条一批重新读取已加载范围，保留卡片直到刷新完成；收藏批量选择作用于“全选已加载”。普通存档仍按存档分页，已加载存档按游戏合并分组；沉浸模式存档列表继续由服务端先按游戏分组，再按每批24款游戏追加。

领域细节统一见[http-api-contract.md](http-api-contract.md)，完整验收见[project-acceptance.md](project-acceptance.md)。

登录页复用统一认证页样式：暗色画布居中480px单卡、34px内边距、紫色R与Retrom品牌行，“欢迎回来”紫色眉题及独立“登录”主标题。用户名／密码保留共享44px控件、自动填充与键盘提交，紫色登录按钮占满表单宽度；底部分隔线后居中说明“新账号需要管理员邀请。本阶段不提供自助找回密码。”。手机使用16px画布边距和20px卡片内边距，卡片内表单不再叠加第二层内边距，品牌／标题／表单／分隔线保持同一网格，内容可自然纵向滚动；登录失败显示共享错误Toast并保留表单可访问错误描述，提交期间禁止重复操作。用户旧版参考为卡片局部裁剪；4K／150%验收使用2560×1440 CSS视口及DPR1.5，卡片物理宽720px，不把裁剪尺寸当作视口。

首页“一直喜欢的”有封面时保持原图片展示；无封面时在原5:7封面槽内显示固定居中的装饰性字母R，不使用游戏标题或首字。卡片尺寸、标题与平台文字布局保持不变；手机仍使用独立首页布局。

游戏库与收藏的浏览卡片不展示游戏标签，保持封面、标题、目录信息与原有辅助行的固定排布，不能因标签数量增加卡片高度。首页及最近页保留各自现有卡片布局；标签仍用于筛选，并在游戏详情与管理编辑中展示。图库卡片“最近游玩”读取当前用户真实lastPlayedAtMs，未玩显示—；紧凑日期显示月／日与时分，完整本地时间保留在title中。手机卡片沿用紧凑布局，不显示该辅助行。

首页平台插画按当前runtime catalog的平台标识解析本地资源；同一硬件家族可复用插画，未知平台或加载失败显示同尺寸手柄占位，不能留下裂图或改变目录卡片高度。


共享控件与布局以 `web/styles/tokens.css` 和 `web/styles/controls.css` 为唯一样式来源；页面只安排间距、尺寸和对齐。按钮、文本框和选择器默认 44px 高，图标与文字垂直居中，组合输入只由外壳绘制边框和焦点环。封面保持 5:7；封面、控件、面板、弹窗分别使用 4/6/8/12px 圆角。桌面侧栏账户行及管理切换按钮均为 44px，账户菜单保留设置/退出图标，服务状态点读取真实 readiness，焦点和悬停均可查看提示。来源扫描与待审核为游戏入库的缩进子项；子项选中时父项保留上下文高亮。左右抽屉统一使用40%深色遮罩、不模糊底层页面；抽屉正文独立滚动，底部动作保持可见。

沉浸入口保留全部游戏、最近游玩、收藏游戏、我的存档及人工目录，按当前 API 返回的真实总数展示，已取消的游玩时长和次数不回填。平台卡片文字左对齐，平台名固定单行并省略超长中文或英文，完整名称保留在标题提示与可访问名称中；相邻卡片高clamp(250px,39dvh,560px)，当前卡片高clamp(330px,48dvh,680px)，名称长度不能改变卡片高度。卡片名称使用完整标题行高，入口说明、名称、数量和操作提示不参与纵向压缩；顶部装饰字母在剩余空间内缩放，紧凑高度只收紧内部纵向留白，不改变主／相邻卡片的宽高、缩放和位置。装饰字母字号由共享 token 按所在槽位高度限制，当前卡片封面叠层保持 5:7 并受内部高度约束。当前卡片保留最近游戏封面叠层与位置指示；游戏列表标题和收藏标识分别对齐，存档名称留在当前游戏的存档区，不提供上一页/下一页按钮。游戏库、收藏、最近与存档游戏列表均在左侧滚动区域接近底部时自动追加，每次24款；键盘/手柄向下浏览到已加载边缘同样触发追加，保留当前选择和已加载内容。追加失败只显示重试，不自动重发；切换收藏夹或目录重置首批。收藏夹选择器留在列表标题区域；存档截图在主预览区域完整展示。空目录可进入并展示空态，不伪造封面或游戏。

沉浸模式保持大屏横向布局（至少 960×540），不满足时提供返回普通界面的明确入口。标准手柄任意按键认领；键盘方向键也可开始浏览。方向键选择、Enter/A 确认、Escape/B 返回、S/Select 系统菜单、Y 收藏、F 全屏；Tab 保留正常焦点移动，弹窗约束焦点并支持 Escape。右上全屏恢复入口与时钟同排且不遮挡时钟。系统菜单保留背景音乐与游戏音量/静音、全屏和退出；背景音乐使用已随应用分发的 Insert Coin OGG，自动播放受阻显示“启用背景音乐”，音量或静音立即生效，离开沉浸界面停止播放。游戏音量在运行就绪后通过 Provider 的公开 setVolume 应用，无法调节时报告错误；控件不能以仅写偏好冒充已调节运行音频。

实际有横向溢出的列表、筛选轨、标签栏、类别轨和表格支持鼠标垂直滚轮横移；只有当前方向还能移动时才消费事件，到边界后恢复页面滚动。原生水平手势、Shift滚动、Ctrl/Meta缩放以及指针内的纵向滚动区域保持原行为；自绘横轨与其实际容器共享位置。手机运行依赖统计栏、图库平台栏和收藏目录外轨使用自由横滚，不启用吸附，避免小步滚轮被拉回；触摸可继续自由滑动。

UI 交付门禁为 `make web-ui-check` 与 `make acceptance-case CASE=ACC-RF-BROWSER`，后者使用质量文档声明的独立数据库/runtime/Provider输入。另需比较真实旧新页面及状态：1440×1000、390×844、2560×1440/DPR1.5，覆盖长列表、空态、焦点、弹层及沉浸音频/输入。静态评审稿仅定义设计，不替代实际产品证据。


游戏详情顶部保留固定预览槽：宽度至少1600px时英雄区高427px；768–1599px时高800px，资料行365px、预览640×360；390px手机下资料行144px、间隔16px、16:9预览。没有媒体时显示“暂无预览”，不能删除槽位。最新存档的截图展示与可恢复性分别判断；收藏心形与开始/恢复控制保留。资料区不设置局部纵向滚动；目录名单行、标题最多两行并保留完整title与可访问文本，窄中列使用现有标题token。收紧信息行间距，内容加载、启动／恢复、提示及运行方式仍完整可达。标签使用36px单行横向栏与thin滚动条，手机标题和心形同排、标签保留可访问筛选链接；左右封面与预览槽尺寸不受内容多少影响。收藏页目录使用单行横向滚动，滚动条高6px，悬停或内部焦点时显示 muted 滑块；不改变文档原生滚动条。浮动收藏夹面板宽250px、最高480px，列表独立滚动而新建按钮固定底部。最近游玩的详情箭头使用16px SVG并与文字垂直居中。

运行核心选择在桌面以“更换”、手机以“启动选项”打开 sheet。后台游戏标签使用固定44px单行 chips 槽位，为标签与可见thin横向滚动条留足高度，禁止纵向滚动或裁切标签；选择标签不推挤编辑区。存档分组保留当前结果内展开/收起、单条存档占位和最近保存时间。

普通文档根滚动区域保留稳定 scrollbar gutter；无文档滚动的Player和沉浸独立屏幕释放该槽位，画面与抽屉贴合视口边界。目录折叠与展开、抽屉打开与关闭不得改变居中内容的横坐标；锁定 body 时只补偿实际释放的布局宽度，不能按消失的原生滚动条再次补偿。移动后台保留当前可用页面；旧版该尺寸仅有管理入口限制，因此后台视觉主对照为桌面与4K，手机验证响应式卡片、抽屉、Toast与操作可用性。

全局 Toast 使用单条替换语义，新通知覆盖当前内容并重新计时，默认3秒关闭；手动关闭后恢复发起控件焦点。成功/提示使用 polite 状态消息，错误使用 assertive alert；全屏内仍可见。写操作成功与执行失败统一通过共享通知；输入校验与未同步存档等持续状态可保留行内说明，不能同时重复弹出两份消息。compact栏服务器状态按钮为44×44，打开就绪详情sheet；只展示当前健康接口实际返回的状态与错误信息。

手机Player必须横屏游玩：竖屏初次进入不加载核心，不记录正在游玩，显示居中旋转提示与返回退出入口；运行中转竖屏暂停同一实例并屏蔽键盘、触屏与手柄游戏输入。横屏后仅恢复方向限制触发的暂停，用户主动暂停、其他操作层或后台状态不得自动恢复。以手机设备身份与屏幕方向判断，桌面窄窗口和平板保留原行为；屏幕方向未确认时不启动。横屏提示标题可省略长游戏名，其他提示自然折行。

Player普通模式顶部左侧只保留返回按钮，不显示游戏名称、核心或平台；右侧保留存档状态、调试、创建存档、暂停、全屏与更多操作。PC鼠标移入顶部整条14px边缘或菜单栏时展开，移开后收起；只悬停不暂停。点击菜单栏任意位置（包括空白和只读操作）请求暂停，重复点击保持暂停；点击游戏画面关闭更多菜单并继续，不能因连续点击菜单误恢复。暂停状态仍允许菜单收起，键盘焦点及活动对话框保持控件可达；触屏保留点击把手、暂停/继续控件。启动按钮在请求Run前使用本次点击请求文档根全屏，审核试玩、重新开始和读档共用；浏览器不支持或拒绝时继续启动并保留手动全屏入口。启动失败只退出本次请求进入的全屏，不改变先前已开启的全屏。展开更多菜单后点击游戏画面将关闭菜单；同源canvas与隔离iframe均需实际点击验证，切换系统窗口不能误关闭。启动时中央440px面板展示最近三项真实启动任务，进度来自LOAD_TASK实际字节，未知进度使用不定动画，不按定时器伪造百分比。桌面模拟器设置为底部820px工具栏，手机使用右侧抽屉；画面模式、音量/静音和原生设置调用现公开能力。独立下载截图入口已移除，存档缩略图和审核封面仍使用截图能力。

普通INSTANT退出先暂停，520px对话框保留标题/说明、内层提示框及“创建存档 / 取消 / 退出游戏”顺序。创建成功后留在对话框并禁用重复创建；失败保留重试入口和草稿。取消按旧版保持暂停，点击画面继续；显式退出离开普通全屏并返回详情。沉浸运行不显示普通HUD，以M或Select+Start双击打开620px横排游戏菜单，默认取消，左右选择、Enter/A确认、Escape/B取消；取消需手柄neutral120ms后仅恢复由菜单暂停的运行。GAME_SAVE手动同步和退出检查均使用EXPORT；捕获/上传失败不得自动导航，必须展示失败及再次明确的退出决定。沉浸退出保留全屏并返回原目录、收藏夹、分页与游戏/存档选中项。只有收到Player返回标记时才将焦点交给新沉浸页面，保留手柄身份与120ms松键等待；返回后的B、方向、A必须继续有效，持续按住退出用的A不能自动重新启动。

游戏窗口快捷键由Provider统一捕获并通过同一V1的HOST_SHORTCUT事件交回Host。普通模式策略为Escape菜单与声明允许的P暂停；沉浸策略仅KeyM菜单。运行游戏时单独Select不打开普通菜单或工具栏，保留核心输入；沉浸游戏的Select+Start双组合和沉浸浏览页S/Select系统菜单保持原行为。弹层打开时策略为空并抑制游戏输入，编辑字段、组合输入、修饰键与重复keydown不触发快捷操作。同源与隔离游戏共用公开setHostShortcutPolicy，Host不跨来源窥探或建立旁路消息。

GAME_SAVE（含J2ME RMS）显示“同步存档 / 取消 / 退出游戏”，不得显示即时快照的“创建存档”。说明明确平台只保存游戏已写入的数据，不保存当前画面的即时进度。同步中的菜单锁定操作；已有草稿可从菜单直接重试。顺序固定为EXPORT、浏览器草稿、服务端持久化、Runtime acknowledge；确认失败保留相同commitId草稿，重试不重复创建存档，成功提示在ack后出现。非菜单卸载等待正在进行的保存，再检查最后的脏数据；同一失败快照复用原草稿，不能生成重复提交。

退出请求只等待公共CHECKPOINTING阶段结束后再按实际运行状态暂停；网络上传期间应立即显示菜单并锁定三项操作，不能把上传等待变成无反馈的返回按钮。等待监听需在成功、失败、退出及卸载时清理，Escape不得同时打开底层更多菜单。

首页接收标准手柄任意按钮的按下边沿，显示“进入沉浸模式？”确认层；摇杆移动或未连接手柄不改变普通首页。触发键需先松开120ms，默认选择取消，左右选择、A/Enter确认、B/Escape取消；取消后经过500ms中立冷却再允许新提示。断开或非标准映射显示准确提示。确认时尝试浏览器全屏并进入沉浸平台页；拒绝全屏不阻断浏览。

游戏修改入口由公开getGameEditor能力决定，仅在RUNNING/PAUSED可用。普通模式位于更多操作，打开前暂停，关闭后仍暂停并将焦点还给更多按钮；沉浸游戏菜单追加“游戏修改”，面板关闭回到原暂停菜单。面板宽880px、最高820px，类别横向滚动、条目内部滚动，使用40项分页和按名称查找；支持金币、物品、装备、变量、开关、角色、技能、状态、职业、队伍和事件独立开关等运行时实际类别。地图和事件读取、修改全部经过公开接口，Host不得读取引擎私有对象。写入成功后才提示，失败可重试；GAME_SAVE说明须在游戏内保存后同步，不能将修改结果称为即时快照。地图选择弹层独立处理Escape/B并回焦点，不能误关闭整个修改面板。

J2ME默认手柄数字键补充为Y→1、L1→3、R1→7、L2→9、R2→0、L3→*、R3→#；方向键/左摇杆、A确认、B/Select右软键、X/Start左软键保持原操作。数字键与方向/FIRE是不同输入，不承诺互相等效。

待审核右上“快速审批”处理当前筛选的全部页：先取得完整候选快照，每批最多100项检查BIOS依赖及CRC提示，审批最多3个并发。无CRC不匹配且无必需BIOS或仅缺少可选BIOS可以批准；缺少必需BIOS保持待审核，检查错误和版本变更分别报告失败，允许重试。运行期间锁定筛选和分页，进度最多展示前20项失败，结束Toast显示真实计数，包括因CRC提示跳过的游戏数。CRC不匹配的条目保持待审核，由用户手动批准；测试运行可选，不能作为人工批准的前置条件。游戏管理“文件与管理操作”保留替换和删除两项，移除内容文件清单，每项按钮右对齐。

待审核详情顶部使用单一紧凑审核栏：封面在左，标题与目录在中，运行、丢弃、发布在右；手机操作移至下方。所有尺寸移除“游戏内容”区和“已接收/已读取”等重复状态。下方的“运行条件检查”仅按已保存配置展示真实结果、具体内容失败原因和缺失必需文件，提供“管理运行依赖”与“重新检查”；审核侧只展示缺失文件名称与核心；具体“文件校验要求”放在运行依赖对应条目中，按核心分别展示已知要求大小、SHA-256或MD5，未知显示“未声明固定大小或校验值。”，长校验值完整折行；“已安装文件／实际大小”独立展示安装事实，不能把已安装摘要当成要求。快速审批结果可展开查看缺失条目及文件，缺少可选项或检查失败不得误标为缺失必需项。ROM、Parent ROM及BIOS的CRC不匹配在运行条件检查下方独立全宽区域提示，文件名和校验值可折行，详细成员与要求/实际CRC默认折叠且内容区域有界滚动；不增列表列宽、不挤占审核栏。CRC不匹配不阻止导入、准备运行或人工批准；缺失文件和大小不符仍按内容规则处理。此检查不限制人工批准，也不代表完整运行验证。审核详情点击“通过并发布”成功后按统一待审核列表默认名称顺序读取首条，并替换导航到该详情；没有待审条目时返回 `/admin/reviews`。发布失败留在原页，发布成功但后续列表读取失败时提示已发布并返回列表，不能误报为发布失败。切换游戏ID需重新建立详情编辑表单；丢弃入口的原有行为保持。

管理与审核详情在桌面并排时，发布信息及媒体标题栏均以原发布信息56px高度为基准，媒体侧减小上下内边距，通用44px控件不缩小；并排时标题基线与分隔线对齐，手机保持既有纵向堆叠，媒体标题及按钮可增高容纳，不裁切控件。支持 DAT 的核心共用可搜索的“ROM 集（DAT）”控件，按 ROM 集短名称、游戏名称与版本搜索当前核心实际构建配套的 DAT，排除 BIOS、设备和不可运行条目。文件名未匹配时保留未选中；已匹配或自选结果均可修改，也可按文件名重新匹配。选择按核心分别保存，切换核心不带入前一核心的条目；返回时恢复该核心的选择。结果列表有界滚动并分页，长名称折行，键盘可选，旧请求取消且延迟结果不覆盖当前选择。更换 ROM 集或入口后先保存，再按新配置检查或上传 Parent；未保存时禁用父包上传。保存只移除不再依赖且没有被其他核心引用的 Parent，并沿用正常延迟清理；保留原始 ROM 与 BIOS 字节。

街机运行配置按所选核心读取已保存配置的runtime父包事实，展示精确缺失ZIP名和上传入口；Parent候选排除游戏入口自身。上传按当前版本直接保存父包并更新该核心配置，成功后重载详情、文件与版本，并保留当前所选运行核心；新游戏重新选择其默认核心，当前核心被移除时才回默认；应先保存其他资料修改，失败保留重试。缺失检查与实际启动校验分离，上传成功不能声称游戏必定可运行。

标签管理搜索保留“搜索标签名称”占位与可访问名称，隐藏可见的“名称搜索”标签，搜索与筛选行为不变。审核与正式游戏共用标签多选器；已选项持续使用紫色背景和文字，不只显示勾。未选项的悬停使用独立的surface-subtle背景，键盘活动项另有轮廓；鼠标移开仍保留全部已选项状态，取消选择后恢复。已选标签气泡复用tag-chip-label文字边缘裁切与flex居中，删除图标在无额外内边距的20px按钮内居中；字号、字重和20px删除按钮保持原样，标签与图标垂直居中，完整显示中英文。

目录管理提供“一键创建推荐目录”，按旧97项产品模板与当前已安装的平台/核心交集创建；已有slug、相同平台与默认核心、或相同平台与推荐名称的目录均跳过（改过默认核心的同名目录仍保留），保留禁用状态和用户配置，部分失败可重试。标签管理提供“一键创建推荐标签”，补齐旧10个常用类型；现有有效标签跳过，删除后同名标签新建且不恢复历史关联。只有精确的名称冲突才计为并发已存在，其余错误必须报告。

管理导航与页面统一称为“运行依赖”；具体BIOS、RTP等运行文件的名称、要求及校验信息按实际条目展示。页面仅提供依赖列表、上传、替换和移除；BIOS扫描入口与进度统一放在“来源扫描”页，模块显示名不改变内部bios路由或数据契约。

DOS审核与游戏管理的运行配置使用可搜索“启动程序”选择器，按完整包内.exe/.com/.bat路径选择，搜索不区分大小写；显式选择“使用核心启动菜单”才移除entryPath。候选仅在DOS编辑控件挂载时读取当前包。换包保留已有显式入口，失效时显示完整旧路径并要求重新选择，刷新后仍提示；原先选择启动菜单时，即使新包只有一个可执行文件也不自动切换。内容文件身份或entryFile变化刷新候选，过时响应不能覆盖当前列表；读取失败保留选择并提供重试，不冒充入口已失效。


来源扫描页并列“游戏扫描”和“BIOS扫描”：游戏扫描只保留“本地扫描”入口，点击后打开右侧目录抽屉；在“服务器目录”下方提供必选的“文件组织形式”下拉框，选项为 metadata.pegasus.txt 和 gamelist.xml。每次打开均未选中，必须手动选择后才能读取来源集合，随后映射目标目录，点击“开始扫描”并成功创建扫描后立即跳转 `/admin/reviews?scanId=<任务ID>`，不等待扫描完成；scanId仅定位当前游戏扫描进度，不参与游戏来源、批次或列表筛选；启动失败保留当前映射与原错误提示。正常进入待审核而未携带scanId时不展示进度。进度按精确任务ID在扫描列表分页查找（每次最多1000条），不替换成其他最新任务；筛选、翻页和刷新保留scanId。总数尚未确定时使用不定进度，展示已扫描、已导入、跳过和失败计数；完成、部分失败、中断及取消分别说明，终态停止轮询。读取失败或未找到任务可重试并进入来源扫描；处理数、导入数或状态变化时自动刷新审核列表。来源扫描中的游戏任务链接同样携带该ID，BIOS任务仍进入运行依赖。BIOS扫描的“平台范围”“核心范围”标题右侧各有独立“勾选框＋全选”控件，覆盖本组全部平台或核心条目（含滚动区未显示项），全选后勾选框选中并切换为“取消全选”；部分勾选时显示半选状态与“全选”，不影响另一组。目录尚未加载或本组为空时禁用全选，提交期间锁定范围操作。成功后保留现有扫描页行为；共用进度列表按scanType显示对应名称和计数，游戏任务进入待审核，BIOS任务进入运行依赖。目录选择从服务进程的 / 开始，不再选择配置来源根；输入绝对路径后点击“进入目录”或按回车才读取，未应用的输入不能启动扫描。目录列表支持进入子目录、上级和读取失败重试，仅展示服务进程实际可见的挂载与权限。内容替换也填写绝对路径；来源只读，接收后复制到受管存储的所有权不变。

Player启动和正常退出使用替换导航，避免浏览器历史重新进入已结束的Run；默认返回地址保留查询参数与锚点，显式沉浸返回仍保留原选择。存档卡片操作菜单在外部点击或打开另一卡片菜单时关闭；Escape关闭并回到触发按钮，外部点击保持目标原有焦点，重命名和删除仍正常执行。

存档大小统一使用十进制 B／KB／MB／GB／TB（1KB = 1000 字节），保留最多一位小数；普通存档卡、详情页存档卡和沉浸存档缩略图均显示大小，并提供精确字节数提示，最近保存摘要同样显示大小。沉浸模式“我的存档”中，每个有存档的游戏只占一个条目；服务端在分页前按游戏分组，左侧列表与平台入口均按游戏计数。上下选择游戏，左右或可见箭头切换当前游戏的存档，A／Enter 加载选中存档。选中项只滚动其所属的游戏列表或存档缩略图区域，不能带动沉浸外层容器与提示层。截图、名称、时间、大小和冻结核心随选择同步；无法恢复的存档允许查看但不能启动：原因以居中蒙层覆盖大图，缩略图中央使用禁止图标，不在底部资料区重复原因。游戏列表向下追加，单个游戏的存档仍左右切换并有界读取；返回地址以 Game ID 标识游戏、Save ID 标识存档，返回后按24款一批恢复到选中游戏所在范围；跨存档页及退出游戏后保留所选存档；切换游戏等待完整存档列表时，使用该游戏在分组列表中已返回的存档截图维持主预览与缩略图布局，不能闪回封面、视频或重建预览节点；显式指定旧存档时不能改用最新存档作为预览。存档标题栏使用独立的左侧标题/计数、中间操作提示、右侧切换按钮三列；计数区始终占位，未知时显示“— / —”，请求开始/结束与数字位数变化不能推动中间提示或按钮。读取超过500ms才显示“正在读取存档”，快速完成时不显示；切换游戏或存档页重新计时，完成或离开后取消提示。错误立即显示并可重试；读取或错误期间始终禁用继续，只有当前请求成功解析的存档可以启动，不能回退启动最新存档。960×540 下存档区至少 240px 高，缩略图、大小和加载按钮完整可见。平台封面按 Game ID 去重后取最多三张，入口显示真实游戏数，右侧单独显示当前游戏的存档总数。

游戏管理详情的“替换游戏内容”和“删除游戏”操作各自采用左侧标题／说明、右侧按钮的同行居中布局，手机按操作区分行但每个按钮仍与自己的说明同行。标签管理从搜索和操作栏直接进入列表，不展示顶部“活动标签”统计容器。Parent 文件等原生多选列表保留滚动和键盘多选语义，不显示单选下拉箭头。

游戏入库与来源扫描首次读取最近100项进度，仅当结果存在pending/running任务时，在上次请求完成3秒后继续读取；空列表、全部终态或读取失败后停止自动请求。页面隐藏时暂停轮询，重新可见时刷新一次；离开页面取消请求和计时器。可用“刷新进度”读取其他管理员新建的任务；本页BIOS扫描成功后立即刷新并按状态恢复轮询。待审核精确scanId进度共用同一轮询节奏，终态仍保留结果。

带有运行配套文件能力的核心在审核页显示统一资源区，上传控件接受 runtime 声明的扩展名；Parent ZIP 与 CHD 光盘分别列出缺失或关联路径，光盘不进入 Parent 多选框。保存入口变更后按当前核心重新检查并清理无其他引用的旧 Parent；审批前试玩保持可选。

存档核心版本变化是可尝试恢复的风险提示，不能显示禁止图标或禁用继续。普通存档卡的黄色“核心版本已变化”标记叠放在截图左上角，游戏详情紧凑卡显示“核心已变化”；继续按钮使用原有尺寸和文字，内含小警示图标，并通过悬停及可访问描述说明风险。首页继续和游戏详情启动入口共用按钮提示，不增加独立提示行。沉浸缩略图以黄色标签提示且保留大图；点击继续后确认“尝试加载旧存档？”，说明可能失败或运行异常、原存档保留及后续进度另存。取消默认获得焦点，普通模式键盘可操作，沉浸模式左右选择、A/Enter确认、B/Escape取消；弹层接管输入，打开/关闭需手柄松键120ms，不能穿透或反复启动。确认在请求全屏前；若服务端发现列表读取后的新核心变化，在加载核心前补充确认，取消释放该Run。ROM变化（含核心同时变化）仍禁用，明确游戏文件与创建存档时不一致；格式不可读、原核心或文件不可用仍显示真实原因。跨版本运行首次真实保存创建新档，后续同步更新新档，本次运行禁止覆盖来源存档。

核心版本警告不得改变卡片正文或操作区高度：同一列表中有／无警告卡片的截图、日期和按钮保持对齐，手机底部启动栏不因警告加高。沉浸模式缩略图保留角标，继续按钮也只放行内警示图标；完整说明由点击后的确认弹窗承载。
