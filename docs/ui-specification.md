# 界面与产品行为

保持共享游戏浏览、管理、私人存档/收藏/最近、账号及独立沉浸模式。手机首页/资料库/我的入口及桌面管理、4K和Player状态以统一docs/design评审源为准。列表采用有界服务端筛选/真实总数；不可恢复存档置灰并展示准确原因；未同步草稿提供重试/丢弃，不假成功。

领域细节统一见[http-api-contract.md](http-api-contract.md)，完整验收见[project-acceptance.md](project-acceptance.md)。


共享控件与布局以 `web/styles/tokens.css` 和 `web/styles/controls.css` 为唯一样式来源；页面只安排间距、尺寸和对齐。按钮、文本框和选择器默认 44px 高，图标与文字垂直居中，组合输入只由外壳绘制边框和焦点环。封面保持 5:7；封面、控件、面板、弹窗分别使用 4/6/8/12px 圆角。桌面侧栏账户行及管理切换按钮均为 44px，账户菜单保留设置/退出图标，服务状态点读取真实 readiness，焦点和悬停均可查看提示。来源扫描与待审核为游戏入库的缩进子项；子项选中时父项保留上下文高亮。左右抽屉统一使用40%深色遮罩、不模糊底层页面；抽屉正文独立滚动，底部动作保持可见。

沉浸入口保留全部游戏、最近游玩、收藏游戏、我的存档及人工目录，按当前 API 返回的真实总数展示，已取消的游玩时长和次数不回填。平台卡片文字左对齐，当前卡片保留最近游戏封面叠层与位置指示；游戏列表标题、收藏标识和存档名称分别对齐，分页按钮不混入游戏行。收藏夹选择器留在列表标题区域；存档截图在主预览区域完整展示。空目录可进入并展示空态，不伪造封面或游戏。

沉浸模式保持大屏横向布局（至少 960×540），不满足时提供返回普通界面的明确入口。标准手柄任意按键认领；键盘方向键也可开始浏览。方向键选择、Enter/A 确认、Escape/B 返回、S/Select 系统菜单、Y 收藏、F 全屏；Tab 保留正常焦点移动，弹窗约束焦点并支持 Escape。右上全屏恢复入口与时钟同排且不遮挡时钟。系统菜单保留背景音乐与游戏音量/静音、全屏和退出；背景音乐使用已随应用分发的 Insert Coin OGG，自动播放受阻显示“启用背景音乐”，音量或静音立即生效，离开沉浸界面停止播放。游戏音量在运行就绪后通过 Provider 的公开 setVolume 应用，无法调节时报告错误；控件不能以仅写偏好冒充已调节运行音频。

UI 交付门禁为 `make web-ui-check` 与 `make acceptance-case CASE=ACC-RF-BROWSER`，后者使用质量文档声明的独立数据库/runtime/Provider输入。另需比较真实旧新页面及状态：1440×1000、390×844、2560×1440/DPR1.5，覆盖长列表、空态、焦点、弹层及沉浸音频/输入。静态评审稿仅定义设计，不替代实际产品证据。


游戏详情顶部保留固定预览槽：宽度至少1600px时英雄区高427px；768–1599px时高800px，资料行365px、预览640×360；390px手机下资料行144px、间隔16px、16:9预览。没有媒体时显示“暂无预览”，不能删除槽位。最新存档的截图展示与可恢复性分别判断；收藏心形与开始/恢复控制保留。资料区允许内部滚动承载长标题与必要操作。收藏页目录使用单行横向滚动，滚动条高6px，悬停或内部焦点时显示 muted 滑块；不改变文档原生滚动条。浮动收藏夹面板宽250px、最高480px，列表独立滚动而新建按钮固定底部。最近游玩的详情箭头使用16px SVG并与文字垂直居中。

运行核心选择在桌面以“更换”、手机以“启动选项”打开 sheet。后台游戏标签使用固定36px单行 chips 槽位，选择标签不推挤编辑区。存档分组保留当前结果内展开/收起、单条存档占位和最近保存时间。

普通文档根滚动区域保留稳定 scrollbar gutter；无文档滚动的Player和沉浸独立屏幕释放该槽位，画面与抽屉贴合视口边界。目录折叠与展开、抽屉打开与关闭不得改变居中内容的横坐标；锁定 body 时只补偿实际释放的布局宽度，不能按消失的原生滚动条再次补偿。移动后台保留当前可用页面；旧版该尺寸仅有管理入口限制，因此后台视觉主对照为桌面与4K，手机验证响应式卡片、抽屉、Toast与操作可用性。

全局 Toast 使用单条替换语义，新通知覆盖当前内容并重新计时，默认3秒关闭；手动关闭后恢复发起控件焦点。成功/提示使用 polite 状态消息，错误使用 assertive alert；全屏内仍可见。写操作成功与执行失败统一通过共享通知；输入校验与未同步存档等持续状态可保留行内说明，不能同时重复弹出两份消息。compact栏服务器状态按钮为44×44，打开就绪详情sheet；只展示当前健康接口实际返回的状态与错误信息。

Player普通模式顶部恢复返回、标题/核心平台、存档状态、调试、创建存档、暂停/继续、全屏与更多操作。启动时中央440px面板展示最近三项真实启动任务，进度来自LOAD_TASK实际字节，未知进度使用不定动画，不按定时器伪造百分比。桌面模拟器设置为底部820px工具栏，手机使用右侧抽屉；画面模式、音量/静音和原生设置调用现公开能力。独立下载截图入口已移除，存档缩略图和审核封面仍使用截图能力。

普通INSTANT退出先暂停，520px对话框保留标题/说明、内层提示框及“创建存档 / 取消 / 退出游戏”顺序。创建成功后留在对话框并禁用重复创建；失败保留重试入口和草稿。取消按旧版保持暂停，点击画面继续；显式退出离开普通全屏并返回详情。沉浸运行不显示普通HUD，以M或Select+Start双击打开620px横排游戏菜单，默认取消，左右选择、Enter/A确认、Escape/B取消；取消需手柄neutral120ms后仅恢复由菜单暂停的运行。GAME_SAVE手动同步和退出检查均使用EXPORT；捕获/上传失败不得自动导航，必须展示失败及再次明确的退出决定。沉浸退出保留全屏并返回原目录、收藏夹、分页与游戏/存档选中项。

游戏窗口快捷键由Provider统一捕获并通过同一V1的HOST_SHORTCUT事件交回Host。普通模式策略为Escape菜单与声明允许的P暂停；沉浸策略仅KeyM菜单。弹层打开时策略为空并抑制游戏输入，编辑字段、组合输入、修饰键与重复keydown不触发快捷操作。同源与隔离游戏共用公开setHostShortcutPolicy，Host不跨来源窥探或建立旁路消息。

GAME_SAVE（含J2ME RMS）显示“同步存档 / 取消 / 退出游戏”，不得显示即时快照的“创建存档”。说明明确平台只保存游戏已写入的数据，不保存当前画面的即时进度。同步中的菜单锁定操作；已有草稿可从菜单直接重试。顺序固定为EXPORT、浏览器草稿、服务端持久化、Runtime acknowledge；确认失败保留相同commitId草稿，重试不重复创建存档，成功提示在ack后出现。非菜单卸载等待正在进行的保存，再检查最后的脏数据；同一失败快照复用原草稿，不能生成重复提交。

退出请求只等待公共CHECKPOINTING阶段结束后再按实际运行状态暂停；网络上传期间应立即显示菜单并锁定三项操作，不能把上传等待变成无反馈的返回按钮。等待监听需在成功、失败、退出及卸载时清理，Escape不得同时打开底层更多菜单。
