# 界面与产品行为

保持共享游戏浏览、管理、私人存档/收藏/最近、账号及独立沉浸模式。手机首页/资料库/我的入口及桌面管理、4K和Player状态以统一docs/design评审源为准。列表采用有界服务端筛选/真实总数；不可恢复存档置灰并展示准确原因；未同步草稿提供重试/丢弃，不假成功。

领域细节统一见[http-api-contract.md](http-api-contract.md)，完整验收见[project-acceptance.md](project-acceptance.md)。

首页“一直喜欢的”有封面时保持原图片展示；无封面时在原5:7封面槽内显示固定居中的装饰性字母R，不使用游戏标题或首字。卡片尺寸、标题与平台文字布局保持不变；手机仍使用独立首页布局。

游戏库与收藏的浏览卡片不展示游戏标签，保持封面、标题、目录信息与原有辅助行的固定排布，不能因标签数量增加卡片高度。首页及最近页保留各自现有卡片布局；标签仍用于筛选，并在游戏详情与管理编辑中展示。图库卡片“最近游玩”读取当前用户真实lastPlayedAtMs，未玩显示—；紧凑日期显示月／日与时分，完整本地时间保留在title中。手机卡片沿用紧凑布局，不显示该辅助行。

首页平台插画按当前runtime catalog的平台标识解析本地资源；同一硬件家族可复用插画，未知平台或加载失败显示同尺寸手柄占位，不能留下裂图或改变目录卡片高度。


共享控件与布局以 `web/styles/tokens.css` 和 `web/styles/controls.css` 为唯一样式来源；页面只安排间距、尺寸和对齐。按钮、文本框和选择器默认 44px 高，图标与文字垂直居中，组合输入只由外壳绘制边框和焦点环。封面保持 5:7；封面、控件、面板、弹窗分别使用 4/6/8/12px 圆角。桌面侧栏账户行及管理切换按钮均为 44px，账户菜单保留设置/退出图标，服务状态点读取真实 readiness，焦点和悬停均可查看提示。来源扫描与待审核为游戏入库的缩进子项；子项选中时父项保留上下文高亮。左右抽屉统一使用40%深色遮罩、不模糊底层页面；抽屉正文独立滚动，底部动作保持可见。

沉浸入口保留全部游戏、最近游玩、收藏游戏、我的存档及人工目录，按当前 API 返回的真实总数展示，已取消的游玩时长和次数不回填。平台卡片文字左对齐，平台名固定单行并省略超长中文或英文，完整名称保留在标题提示与可访问名称中；相邻卡片高clamp(250px,39dvh,560px)，当前卡片高clamp(330px,48dvh,680px)，名称长度不能改变卡片高度。当前卡片保留最近游戏封面叠层与位置指示；游戏列表标题、收藏标识和存档名称分别对齐，分页按钮不混入游戏行。收藏夹选择器留在列表标题区域；存档截图在主预览区域完整展示。空目录可进入并展示空态，不伪造封面或游戏。

沉浸模式保持大屏横向布局（至少 960×540），不满足时提供返回普通界面的明确入口。标准手柄任意按键认领；键盘方向键也可开始浏览。方向键选择、Enter/A 确认、Escape/B 返回、S/Select 系统菜单、Y 收藏、F 全屏；Tab 保留正常焦点移动，弹窗约束焦点并支持 Escape。右上全屏恢复入口与时钟同排且不遮挡时钟。系统菜单保留背景音乐与游戏音量/静音、全屏和退出；背景音乐使用已随应用分发的 Insert Coin OGG，自动播放受阻显示“启用背景音乐”，音量或静音立即生效，离开沉浸界面停止播放。游戏音量在运行就绪后通过 Provider 的公开 setVolume 应用，无法调节时报告错误；控件不能以仅写偏好冒充已调节运行音频。

实际有横向溢出的列表、筛选轨、标签栏、类别轨和表格支持鼠标垂直滚轮横移；只有当前方向还能移动时才消费事件，到边界后恢复页面滚动。原生水平手势、Shift滚动、Ctrl/Meta缩放以及指针内的纵向滚动区域保持原行为；自绘横轨与其实际容器共享位置。手机运行依赖统计栏、图库平台栏和收藏目录外轨使用自由横滚，不启用吸附，避免小步滚轮被拉回；触摸可继续自由滑动。

UI 交付门禁为 `make web-ui-check` 与 `make acceptance-case CASE=ACC-RF-BROWSER`，后者使用质量文档声明的独立数据库/runtime/Provider输入。另需比较真实旧新页面及状态：1440×1000、390×844、2560×1440/DPR1.5，覆盖长列表、空态、焦点、弹层及沉浸音频/输入。静态评审稿仅定义设计，不替代实际产品证据。


游戏详情顶部保留固定预览槽：宽度至少1600px时英雄区高427px；768–1599px时高800px，资料行365px、预览640×360；390px手机下资料行144px、间隔16px、16:9预览。没有媒体时显示“暂无预览”，不能删除槽位。最新存档的截图展示与可恢复性分别判断；收藏心形与开始/恢复控制保留。资料区不设置局部纵向滚动；目录名单行、标题最多两行并保留完整title与可访问文本，窄中列使用现有标题token。收紧信息行间距，内容加载、启动／恢复、提示及运行方式仍完整可达。标签使用36px单行横向栏与thin滚动条，手机标题和心形同排、标签保留可访问筛选链接；左右封面与预览槽尺寸不受内容多少影响。收藏页目录使用单行横向滚动，滚动条高6px，悬停或内部焦点时显示 muted 滑块；不改变文档原生滚动条。浮动收藏夹面板宽250px、最高480px，列表独立滚动而新建按钮固定底部。最近游玩的详情箭头使用16px SVG并与文字垂直居中。

运行核心选择在桌面以“更换”、手机以“启动选项”打开 sheet。后台游戏标签使用固定44px单行 chips 槽位，为标签与可见thin横向滚动条留足高度，禁止纵向滚动或裁切标签；选择标签不推挤编辑区。存档分组保留当前结果内展开/收起、单条存档占位和最近保存时间。

普通文档根滚动区域保留稳定 scrollbar gutter；无文档滚动的Player和沉浸独立屏幕释放该槽位，画面与抽屉贴合视口边界。目录折叠与展开、抽屉打开与关闭不得改变居中内容的横坐标；锁定 body 时只补偿实际释放的布局宽度，不能按消失的原生滚动条再次补偿。移动后台保留当前可用页面；旧版该尺寸仅有管理入口限制，因此后台视觉主对照为桌面与4K，手机验证响应式卡片、抽屉、Toast与操作可用性。

全局 Toast 使用单条替换语义，新通知覆盖当前内容并重新计时，默认3秒关闭；手动关闭后恢复发起控件焦点。成功/提示使用 polite 状态消息，错误使用 assertive alert；全屏内仍可见。写操作成功与执行失败统一通过共享通知；输入校验与未同步存档等持续状态可保留行内说明，不能同时重复弹出两份消息。compact栏服务器状态按钮为44×44，打开就绪详情sheet；只展示当前健康接口实际返回的状态与错误信息。

Player普通模式顶部左侧只保留返回按钮，不显示游戏名称、核心或平台；右侧保留存档状态、调试、创建存档、暂停/继续、全屏与更多操作。展开更多菜单后点击游戏画面将关闭菜单；同源canvas与隔离iframe均需实际点击验证，切换系统窗口不能误关闭。启动时中央440px面板展示最近三项真实启动任务，进度来自LOAD_TASK实际字节，未知进度使用不定动画，不按定时器伪造百分比。桌面模拟器设置为底部820px工具栏，手机使用右侧抽屉；画面模式、音量/静音和原生设置调用现公开能力。独立下载截图入口已移除，存档缩略图和审核封面仍使用截图能力。

普通INSTANT退出先暂停，520px对话框保留标题/说明、内层提示框及“创建存档 / 取消 / 退出游戏”顺序。创建成功后留在对话框并禁用重复创建；失败保留重试入口和草稿。取消按旧版保持暂停，点击画面继续；显式退出离开普通全屏并返回详情。沉浸运行不显示普通HUD，以M或Select+Start双击打开620px横排游戏菜单，默认取消，左右选择、Enter/A确认、Escape/B取消；取消需手柄neutral120ms后仅恢复由菜单暂停的运行。GAME_SAVE手动同步和退出检查均使用EXPORT；捕获/上传失败不得自动导航，必须展示失败及再次明确的退出决定。沉浸退出保留全屏并返回原目录、收藏夹、分页与游戏/存档选中项。只有收到Player返回标记时才将焦点交给新沉浸页面，保留手柄身份与120ms松键等待；返回后的B、方向、A必须继续有效，持续按住退出用的A不能自动重新启动。

游戏窗口快捷键由Provider统一捕获并通过同一V1的HOST_SHORTCUT事件交回Host。普通模式策略为Escape菜单与声明允许的P暂停；沉浸策略仅KeyM菜单。运行游戏时单独Select不打开普通菜单或工具栏，保留核心输入；沉浸游戏的Select+Start双组合和沉浸浏览页S/Select系统菜单保持原行为。弹层打开时策略为空并抑制游戏输入，编辑字段、组合输入、修饰键与重复keydown不触发快捷操作。同源与隔离游戏共用公开setHostShortcutPolicy，Host不跨来源窥探或建立旁路消息。

GAME_SAVE（含J2ME RMS）显示“同步存档 / 取消 / 退出游戏”，不得显示即时快照的“创建存档”。说明明确平台只保存游戏已写入的数据，不保存当前画面的即时进度。同步中的菜单锁定操作；已有草稿可从菜单直接重试。顺序固定为EXPORT、浏览器草稿、服务端持久化、Runtime acknowledge；确认失败保留相同commitId草稿，重试不重复创建存档，成功提示在ack后出现。非菜单卸载等待正在进行的保存，再检查最后的脏数据；同一失败快照复用原草稿，不能生成重复提交。

退出请求只等待公共CHECKPOINTING阶段结束后再按实际运行状态暂停；网络上传期间应立即显示菜单并锁定三项操作，不能把上传等待变成无反馈的返回按钮。等待监听需在成功、失败、退出及卸载时清理，Escape不得同时打开底层更多菜单。

首页接收标准手柄任意按钮的按下边沿，显示“进入沉浸模式？”确认层；摇杆移动或未连接手柄不改变普通首页。触发键需先松开120ms，默认选择取消，左右选择、A/Enter确认、B/Escape取消；取消后经过500ms中立冷却再允许新提示。断开或非标准映射显示准确提示。确认时尝试浏览器全屏并进入沉浸平台页；拒绝全屏不阻断浏览。

游戏修改入口由公开getGameEditor能力决定，仅在RUNNING/PAUSED可用。普通模式位于更多操作，打开前暂停，关闭后仍暂停并将焦点还给更多按钮；沉浸游戏菜单追加“游戏修改”，面板关闭回到原暂停菜单。面板宽880px、最高820px，类别横向滚动、条目内部滚动，使用40项分页和按名称查找；支持金币、物品、装备、变量、开关、角色、技能、状态、职业、队伍和事件独立开关等运行时实际类别。地图和事件读取、修改全部经过公开接口，Host不得读取引擎私有对象。写入成功后才提示，失败可重试；GAME_SAVE说明须在游戏内保存后同步，不能将修改结果称为即时快照。地图选择弹层独立处理Escape/B并回焦点，不能误关闭整个修改面板。

J2ME默认手柄数字键补充为Y→1、L1→3、R1→7、L2→9、R2→0、L3→*、R3→#；方向键/左摇杆、A确认、B/Select右软键、X/Start左软键保持原操作。数字键与方向/FIRE是不同输入，不承诺互相等效。

待审核右上“快速审批”处理当前筛选的全部页：先取得完整候选快照，每批最多100项仅检查BIOS依赖，审批最多3个并发。无必需BIOS或仅缺少可选BIOS可以批准；缺少必需BIOS保持待审核，检查错误和版本变更分别报告失败，允许重试。运行期间锁定筛选和分页，进度最多展示前20项失败，结束Toast显示真实计数。游戏管理“文件与管理操作”保留替换和删除两项，移除内容文件清单，每项按钮右对齐。

待审核详情顶部使用单一紧凑审核栏：封面在左，标题与目录在中，运行、丢弃、发布在右；手机操作移至下方。所有尺寸移除“游戏内容”区和“已接收/已读取”等重复状态。下方的BIOS检查仅按已保存配置展示真实结果和缺失必需文件，提供“管理运行依赖”与“重新检查”；审核侧只展示缺失文件名称与核心；具体“文件校验要求”放在运行依赖对应条目中，按核心分别展示已知要求大小、SHA-256或MD5，未知显示“未声明固定大小或校验值。”，长校验值完整折行；“已安装文件／实际大小”独立展示安装事实，不能把已安装摘要当成要求。快速审批结果可展开查看缺失条目及文件，缺少可选项或检查失败不得误标为缺失必需项。此检查不限制人工批准，也不代表完整运行验证。

标签管理搜索保留“搜索标签名称”占位与可访问名称，隐藏可见的“名称搜索”标签，搜索与筛选行为不变。审核与正式游戏共用标签多选器；已选项持续使用紫色背景和文字，不只显示勾。未选项的悬停使用独立的surface-subtle背景，键盘活动项另有轮廓；鼠标移开仍保留全部已选项状态，取消选择后恢复。已选标签气泡复用tag-chip-label文字边缘裁切与flex居中，删除图标在无额外内边距的20px按钮内居中；字号、字重和20px删除按钮保持原样，标签与图标垂直居中，完整显示中英文。

目录管理提供“一键创建推荐目录”，按旧97项产品模板与当前已安装的平台/核心交集创建；已有slug、相同平台与默认核心、或相同平台与推荐名称的目录均跳过（改过默认核心的同名目录仍保留），保留禁用状态和用户配置，部分失败可重试。标签管理提供“一键创建推荐标签”，补齐旧10个常用类型；现有有效标签跳过，删除后同名标签新建且不恢复历史关联。只有精确的名称冲突才计为并发已存在，其余错误必须报告。

管理导航与页面统一称为“运行依赖”；具体BIOS、RTP等运行文件的名称、要求及校验信息按实际条目展示。页面仅提供依赖列表、上传、替换和移除；BIOS扫描入口与进度统一放在“来源扫描”页，模块显示名不改变内部bios路由或数据契约。

DOS审核与游戏管理的运行配置使用可搜索“启动程序”选择器，按完整包内.exe/.com/.bat路径选择，搜索不区分大小写；显式选择“使用核心启动菜单”才移除entryPath。候选仅在DOS编辑控件挂载时读取当前包。换包保留已有显式入口，失效时显示完整旧路径并要求重新选择，刷新后仍提示；原先选择启动菜单时，即使新包只有一个可执行文件也不自动切换。内容文件身份或entryFile变化刷新候选，过时响应不能覆盖当前列表；读取失败保留选择并提供重试，不冒充入口已失效。


来源扫描页并列“游戏扫描”和“BIOS扫描”：游戏扫描选择Pegasus或EmulationStation后映射目标目录，BIOS扫描选择平台／核心范围；共用进度列表按scanType显示对应名称和计数，游戏任务进入待审核，BIOS任务进入运行依赖。目录选择从服务进程的 / 开始，不再选择配置来源根；输入绝对路径后点击“进入目录”或按回车才读取，未应用的输入不能启动扫描。目录列表支持进入子目录、上级和读取失败重试，仅展示服务进程实际可见的挂载与权限。内容替换也填写绝对路径；来源只读，接收后复制到受管存储的所有权不变。

Player启动和正常退出使用替换导航，避免浏览器历史重新进入已结束的Run；默认返回地址保留查询参数与锚点，显式沉浸返回仍保留原选择。存档卡片操作菜单在外部点击或打开另一卡片菜单时关闭；Escape关闭并回到触发按钮，外部点击保持目标原有焦点，重命名和删除仍正常执行。
