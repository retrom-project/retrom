# FBAlpha 0.2.97.44 候选验证

本次在独立 `fbalpha-029744` PFB 接入 `emulatorjs/fbalpha`，内容范围为街机 ZIP。核心 fork 为 `retrom-project/fbalpha`，上游为 `libretro/beetle-finalarcade2019` 的 `b25b724ba204`；驱动源码与授权 Pegasus 样本使用的 0.2.97.44 构建一致。没有数据库、HTTP 契约或生产 Provider pin 变更。

## 实现边界

- 从同次发货 Wasm 导出 5,807 个 DAT 条目，其中 8 个 BIOS；运行时复用已有 DAT 搜索、按核心保存的 ROM 集选择、Parent 清理及 BIOS/ROM 校验。
- 核心原生装载回执区分真正接受与拒绝。EmulatorJS 注册街机分类，完整 ZIP、独立 BIOS 及 Parent 保持原字节；没有按游戏编写别名、补丁或特例。
- 输入使用共享街机映射；即时存档使用公共压缩格式；内容使用公共持久缓存，启动选项固定为下载完成后开始。
- 核心、DAT、配对证明和许可共同构成候选资产。固定 SDK、前端提交、构建时间、Git 版本输入和 SHA-256 固定的 7-Zip 25.01；压缩使用单线程。

## 产品验证范围

21 款授权问题样本通过正常 Pegasus 扫描导入，全部带封面与 `hack` 标签。补齐原始 Neo Geo / PGM BIOS 后，审核检查没有必需成员缺失；81 条 CRC 差异仍保留人工审核警告，测试在明确人工批准后发布到 PFB。BIOS 使用正常上传入口安装；本轮不把自动 BIOS 扫描记为通过。

21 款均完成审核预览、发布游玩、投币、开局及主要操作。浏览器通过标准 Gamepad API 注入按键，方向和攻击后的可观察画面均人工复核；21 份挂载 ZIP 的 SHA-256 与原始样本一致，Neo Geo 独立 BIOS 的挂载摘要也核对一致。覆盖开局与短时战斗，不代表通关或所有 FBA 游戏兼容。

`captcomm` 代表样本验证即时存档、不同 Run 和仅保留登录态的新 Chromium 恢复：保留战斗场景、角色与状态，公开暂停七秒后继续方向和攻击。断网后输入有效；关闭普通 HTTP 缓存后，全量缓存确认一个 2,541,859 字节的游戏文件，新实例未再请求游戏内容。下载中退出能取消启动；人为限制存储配额时页面明确显示存储不可用。

通过正常审核配置接口验证 FBA 条目切换，以及与 FBNeo、MAME 2003、MAME 2003 Plus、MAME current 之间的选择隔离。共享 Parent 退休/保留行为覆盖五种核心的确定性单元回归。现有 FBNeo 的 1941 另行通过真实加载与移动/射击回归。
