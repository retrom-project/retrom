# BIOS 与街机依赖

需求来自runtime实际Target声明。公共列表按requirementKey聚合消费者核心/平台，数据库批量读取当前安装；共享需求只显示和安装一次。installed表示有当前文件，不代替本次运行可用性检查。

自动扫描先按需求key去重并设置要求总数。已有active安装跳过；相同内容源去重，多种符合内容视为歧义并跳过；无匹配跳过，无关源文件不计进度。严格hash/文件识别只用于自动来源扫描。每独立要求拥有bios/<bios-file-id>/文件，安装和成功进度同事务；唯一冲突计skip，不退休或覆盖并发手动安装。

BIOS 来源扫描最多枚举 100000 个文件，递归子目录的文件合并计入总数；超过上限以 SOURCE_INVALID 结束扫描。

手动上传/替换只检查requirementKey存在、文件安全/非空/大小，记录实际SHA，不以已知BIOS摘要校验门禁，也不触发游戏重审核或全库验证。旧安装deleted，current只有一条。删除当前安装同样由文件生命周期清理。

街机DAT、实际ZIP成员、Parent闭包和BIOS需求由runtime准备解析，Go不截取第一个Parent或猜核心规则。多个Parent通过统一parent-archive输出一个规范受管归档。缺依赖在正式启动/试玩准确失败，列表与普通资料编辑不装配完整运行资源。
