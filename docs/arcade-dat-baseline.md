# 街机事实源

实际 Target 对应的固定 DAT、Parent 闭包、BIOS 与 ZIP 成员解释均归 runtime。Retrom 提交受控文件事实与受管 locator，消费 ROM 集搜索、缺项、审核及资源计划的统一投影；Go／Web 不复制 DAT 或按文件名猜测核心规则。

DAT 应与实际发货核心的构建名录配套，不能混用另一个版本的通用 ROM 集。源码维护分支、核心发行、DAT 素材身份、Provider／Target 指纹分别记录；DAT 的来源标签不选择当前运行 Provider。升级以[配套输入](dependency-management.md)认证的资产为准，存档按[当前身份规则](runtime-and-play-data.md)判断。

管理员操作及必需成员／CRC／CHD 边界见[BIOS 与街机依赖](bios-and-arcade.md)。核心侧说明见 runtime 的[街机 Target 指南](https://github.com/retrom-project/retrom-runtime/blob/master/docs/targets/arcade.md)，产品验证要求见[运行产品验证边界](core-runtime-validation.md)。
