# 收藏与收藏夹

收藏和收藏夹属于当前 User，管理员也不能读取或修改其他用户的私人分类。共享游戏资料与运行配置不因收藏操作而改变。

## 整理与未分类

同一收藏游戏可以同时加入多个收藏夹，也可以不属于任何收藏夹。“未分类”只包含已收藏且没有任何收藏夹成员关系的游戏。

删除收藏夹只删除该夹及其成员关系，保留收藏和其他夹中的成员关系。例如游戏同时属于 A、B 两夹，删除 A 后仍在 B 中；删除最后一个所属夹后才进入未分类。取消收藏会同时清除该游戏的全部收藏夹成员关系。

“整理收藏夹”保存的是该游戏的完整目标夹集合。空集合表示保留收藏但移出所有夹；夹 ID 必须属于当前用户，不允许重复，一款游戏最多关联 100 个收藏夹。夹的新建与改名遵循名称规则，改名使用当前版本防止覆盖另一页的修改。

## 查询与可见性

`folderId` 与 `unclassified` 筛选互斥，筛选在服务端分页前执行。普通收藏列表只返回当前可公开读取的游戏；游戏退回审核时私人关系仍保留，重新发布后按原关系展示。

请求及字段见 [Favorites API](../api/domains/favorites.yaml)和[HTTP 契约](http-api-contract.md)，关系定义见[数据模型](data-model.md)，验证要求见[项目验收](project-acceptance.md)。
