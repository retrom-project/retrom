## Contract and implemented behavior

`api/openapi.yaml` is authoritative for `/api/v1`; the public provider boundary remains `PlayerRuntimeV1`. Enabled checkpoints explicitly declare `INSTANT` or `GAME_SAVE`. Generated browser/runtime declarations must match the existing generation. Each raw resource URL retains its logical basename at `/api/v1/runs/{runId}/resources/{resourceId}/{filename}`; each index uses `/resources/index/{indexId}`. Consumers use the declared URLs. Raw resources and save payloads expose strong `"sha256-<hash>"` ETags, optional If-Match, and byte ranges. HEAD on the same authorized path has no body; valid Range HEAD returns 206 with the selected Content-Length and Content-Range, while identity mismatch returns 412 with an empty body. The browser restore GET and the independent conditional HTTP matrix are separate evidence; the observed UI request did not send If-Match. Isolation assets have one canonical path, `/__retrom/runtime-isolation/{runId}/{asset}`. There are no compatibility aliases, upload tickets, multi-disc controls or generated/formal-document dependencies on working design notes.

Pages consume the new Game, directory, save, scan and account data. Home retains the save-screenshot Hero, recent rail, horizontal favorites, platform rail and real game/save totals. Detail retains its poster, launch controls, save/video preview, information and compact saves. Phone navigation and cover geometry are retained. The restored pure HUD state hides an unpinned RUNNING toolbar after two seconds; hover, keyboard focus, pause and open dialogs retain access. Revealing controls does not resize or remount the game frame. This corrects the earlier always-visible toolbar that covered native titles. Resume intentionally focuses the native core; this does not claim that Tab exits an active core which consumes that key. The earlier red overlap and source checks remain in `hud-auto-hide-candidate/handle-quality-proof.json`. Affected browser verification is recorded separately from the 28-page gallery. Library sorting and platform/directory/tag filters query the server; changing recent filters resets pagination. Favorite circles remain at the cover corner. Game scan cards link to the shared review list; BIOS scan cards link to BIOS management.

IndexedDB drafts retain creator user ID, commitId, saveId, original expected version, complete frozen Run extinfo, opaque checkpoint and optional screenshot. Retry reuses the same commitId. Creation uses `POST /api/v1/saves`; overwrite uses `PUT /api/v1/saves/{saveId}`. An instant save with a current selection offers explicit new/overwrite choices; native automatic saves do not open that sheet. `VERSION_CONFLICT` explains in Chinese that another page updated the save, the draft is retained and retry will not force an overwrite. Neither retry nor context renewal updates the draft's expected version.

After context expiry, a new authenticated Run must have structurally identical extinfo before it may supply a replacement runId. Every temporary Run closes after success, failure or mismatch. Changed identity retains a disabled draft; disconnects retain a retryable draft. Native acknowledgement happens only after durable success. Acknowledging an older draft also reads current checkpoint availability so a newer native revision is captured without depending on a repeated event. Exported `.retrom-save` backups retain frozen recovery metadata and both binaries; there is no automatic product backup-import flow. Review checkpoints remain in memory through a LOCAL descriptor. Browser-storage failure retains a temporary exportable draft in the current document and reports the failure.

Isolated frames contain no login cookie or backend credential. Manifest-admitted resource paths use the provider's current Window-bound STAT/READ channel; only the authenticated host fetches owner resource URLs. Script, import, Worker, audio, video and Range responses retain the same bounded admission, CSP, CORP and COEP policy. Project-supplied service-worker registration is rejected. Same-origin blank frames await their initial navigation before exposing the settled Document. Runtime-dependent controls and callbacks remain disabled until RUNNING or PAUSED; browser fullscreen, menu and exit are available independently. Screenshot transport, downloads and review-cover uploads preserve actual PNG/JPEG bytes and MIME.
