# NES 与街机手柄摇杆验证

标准手柄左摇杆可用于数字方向移动，同时保留方向键。FCEUmm、Nestopia、FBNeo、FBAlpha、FBA2012 CPS1/CPS2、MAME 2003/Plus 共用 EmulatorJS 轮询适配；MAME current 保留已有摇杆方向实现。模拟摇杆主机不经过该转换。

摇杆绝对轴值达到 0.5 时触发，回落到 0.35 时释放。方向键在同一轴上优先，另一轴允许组合斜向；松开一个输入来源不会解除另一来源仍保持的方向。断开控制器释放按键，重新连接不继承方向状态。

## 验证范围

通过正常扫描、审核预览和公开游戏入口启动真实 ROM，使用 Chrome 的标准 Gamepad API 模拟控制器，观察实际核心收到的输入和游戏画面。未使用实体手柄。仅验证输入，不将本次结果表述为存档恢复或完整通关验收。
