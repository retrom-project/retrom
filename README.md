# Retrom v0.0.104 异常路径 UI 证据

2026-10-03，真实部署、Chromium。使用 1280×800、2560×1440，用户页面补充 390×844，播放器补充 844×390；账号状态单独在 1440×900 确认。

自然触发：错误登录、密码确认不一致、错误当前密码、Parent 未选文件。其他失败由浏览器局部拦截指定请求返回 503/409/429 或断开请求；目录读取失败由浏览器局部注入 NotReadableError。注入用于验证发布版本的失败展示，不代表线上服务自然返回这些故障。

- `geometry.json`：筛选后的布局、按钮坐标及遮挡测量。
- `account-state.json`：业务密码错误与有效会话产生的客户端状态冲突。
- `screenshots/`：实际浏览器截图。批次丢弃仅截取弹窗，因此失败前后外观一致；错误出现在弹窗外且被遮挡的证据见 geometry.json。

所有修复建议以允许破坏性重构为前提；优先复用现有 ToastProvider，顶部居中，不将业务状态放入通用组件。阻断启动、未保存草稿等需要持续决策的状态保留稳定的上下文和恢复按钮。

这是问题复现证据，不是修复后验收。未公开部署地址、凭据、原始服务端路径或网络会话资料。
